# مستندات محصولات راست چین

## 🚀 شروع کار با قالب

#### 1. یک پوشه جدید با نام `docs` در مسیر روت پروژه ایجاد کنید.

#### 2. در مسیر `docs` پوشه هایی که میخواهید مستندات خود را در آن قرار دهید ایجاد کنید.

#### 3. سپس در هر پوشه محتوای مستندات خود را در فایل های `md` قرار دهید.

#### ساختار

```bash
rtl-theme-docs/
├─ docs/
│ ├─ help-1/
│ │ ├─ intro-1.md
│ │ ├─ changelog.md
│ ├─ help-2/
│ │ ├─ intro-2.md
│ │ ├─ donate.md
│ ├─ help-_/
│ │ ├─ example.md
```

#### 5. فایل `sidebars.js` را باز کنید و منوهای کناری فعلی را جایگزین خود کنید

#### 6. فایل `src/pages/index.js` را باز و لینک مستندات خود را به صفحه اصلی اضافه کنید

> برای اطلاعات بیشتر به مستندات [docusaurus](https://docusaurus.io/) مراجعه کنید
