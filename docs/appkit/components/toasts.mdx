# تُست ها

:::rtnote نکته

این المان باید خارج از محتوای صفحه قرار گیرد

:::

با پیروی از دستورالعمل‌های ذکر شده در [مستندات بوت استرپ](https://getbootstrap.com/docs/5.3/components/toasts/) میتوان از تُست‌های پیشفرض بوت استرپ استفاده کرد و به‌صورت دستی یا کدنوسی با استفاده از تُست های ما راه‌اندازی کرد.

```html showLineNumbers
<div
  id="toast-1"
  class="toast toast-tiny toast-top bg-blue2-dark"
  data-delay="3000"
  data-autohide="true"
>
  <i class="fa fa-check mr-3"></i>
  All Good!
</div>
```

**خط 2** حاوی آی دی تست است، این آی دی برای فعال کردن تست استفاده خواهد شد. فقط کافیست از `data-toast="unique-toast-id"` روی المانی که میخواهید تست را فعال کند، استفاده کنید.

**خط 3** شامل کلاس‌ تست است. کلاس تست برای شناسایی تست در جاوا اسکریپت بوت‌استرپ استفاده میشود. `toast-tiny` کلاسی است که ما برای استایل‌بندی استفاده میکنیم.\
این خط همچنین شامل `toast-top` یا `toast-bottom` بسته به جایی که میخواهید تست شما از آنجا نمایش داده شود، است و آخرین الامان، رنگ پس‌زمینه مورد نظر شماست که میتوانید از [کلاس های کمکی](/appkit/color-highlights-backgrounds#%DA%86%D9%87-%D8%B1%D9%86%DA%AF-%D9%87%D8%A7%DB%8C%DB%8C-%D8%A8%D9%87-%D8%B7%D9%88%D8%B1-%D9%BE%DB%8C%D8%B4%D9%81%D8%B1%D8%B6-%DA%AF%D9%86%D8%AC%D8%A7%D9%86%D8%AF%D9%87-%D8%B4%D8%AF%D9%87-%D8%A7%D8%B3%D8%AA) انتخاب کنید.

**خط 4 و 5** مربوط به تأخیر نمایش تست، تست به طور خودکار پنهان میشود. زمان بر حسب میلی‌ ثانیه است.

**خط 6** آیکون تست است.

به تعداد مورد نیاز تست ایجاد کنید، فقط مطمئن شوید که آی دی هر کدام منحصر به فرد است.

## چگونه میتوانم با کدنویسی تست ها را فعال کنم؟
