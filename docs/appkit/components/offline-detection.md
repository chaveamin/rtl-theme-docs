# تشخیص آفلاین

سیستم تشخیص آفلاین، خودکار است و بسته به اینکه آنلاین هستید یا نه، یک متن کوچک قرمز یا سبز نشان میدهد. این پیام ها را میتوان از طریق **scripts/pwa.js** با جستجوی `"Offline Alerts"` ویرایش کرد.
