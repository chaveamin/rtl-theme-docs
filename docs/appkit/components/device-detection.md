# تشخیص دستگاه

برای نمایش محتوای مختلف برای سیستم عامل های مختلف، فرآیند فوق العاده ساده است. تنها کاری که باید انجام دهید این است که کلاس `show-android` را برای نمایش در دستگاه های اندرویدی یا `show-ios` را برای نمایش در دستگاه های iOS اضافه کنید. همچنین میتوانید کلاس `show-no-device` را اضافه کنید تا برای دستگاه‌هایی که Android یا iOS نیستند نمایش داده شود.
