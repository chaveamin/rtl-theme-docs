# پیش‌ بارگذار(preloader)

پیش‌ بارگذار به طور خودکار با استفاده از سیستم انتقال AJAX به همه صفحات اضافه میشود و پس از بارگذاری صفحه مخفی میشود.

```html
<div id="preloader">
  <div class="spinner-border color-highlight" role="status"></div>
</div>
```
