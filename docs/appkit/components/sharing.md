# اشتراک گذاری

قابلیت اشتراک گذاری خودکار برای وب سایت شما وقتی در حالت دسکتاپ استفاده میشود عالی عمل میکند. با این حال، اگر قصد دارید از صفحه به عنوان PWA استفاده کنید، قالب هنوز به API دسترسی ندارد تا لینک محل ذخیره PWA شما را انتخاب کند و آن لینک را مستقیماً به اشتراک بگذارد.

با افزودن کلاس‌های زیر به دکمه‌هایی که میخواهید اشتراک‌گذاری را فعال کنید، میتوانید صفحه‌ای را که این دکمه‌ها در آن قرار میگیرند به‌طور خودکار به اشتراک بگذارید.

- shareToFacebook
- shareToTwitter
- shareToLinkedIn
- shareToPinterest
- shareToWhatsApp
- shareToMail

اگر میخواهید از یک آدرس از پیش تعریف شده استفاده کنید یا به اشتراک بگذارید، **custom.js** را باز کرده و کد زیر را جستجو کنید

```js
var share_link = window.location.href;
```

اکنون، ما باید لینک صفحه پیشفرض را با صفحه ای که میخواهید استفاده کنید جایگزین کنیم. کد بالا را با کد زیر جایگزین کنید

```js
var share_link = "https://awesome-buyer-domain.com";
```
