# آپلود فایل ها

آپلود فایل به شما این امکان را میدهد که تصاویر را آپلود کنید و نام، اندازه و داده های آنها را نمایش دهید کنید. این فقط یک المان فرانت اند است که میتوان آن را در داخل **custom.js** با جستجوی برای `upload-file` برای یافتن کد آن پیدا کرد. شما میتوانید از منطق کد خود برای تطبیق جاوا اسکریپت برای نیازهای خود استفاده کنید.

بطور پیشفرض، این المان در **component-file-upload.html** یافت میشود، و شما میتوانید فقط از تگ `file-data` استفاده کنید تا فقط از ورودی فایل آپلود استفاده کنید یا از `upload-file-data` در زیر آن نیز برای دریافت اطلاعات لیست که در مورد آنچه تصویر حاوی آن است دریافت کنید.
