# ساخت کیو آر کد

قالب از یک API برای تولید فوری کدهای QR استفاده میکند، بنابراین برای تولید اسکریپت ها به api های پیچیده PHP نیاز ندارید. این میتواند هر کد QR را به سادگی با استفاده از ساختار زیر ایجاد کند.

<!-- prettier-ignore -->
```html
<img src="https://api.qrserver.com/v1/create-qr-code/?size=200x200&data=ENTER_YOUR_FULL_URL_HERE">
```

کد بالا را کپی و پیست کنید و آدرس خود را جایگزین `ENTER_YOUR_FULL_URL_HERE` کنید. پس از انجام، ذخیره و رفرش صفحه، کد QR به طور خودکار نمایش داده میشود.

```html
<img class="generate-qr-auto" src="" />
```

کد بالا به طور خودکار یک کد QR برای آدرسی که کد به آن اضافه شده است ایجاد میکند.
