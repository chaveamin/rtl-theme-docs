# مسیر سایت

این ویژگی با استفاده از المان Breadcrumb پیشفرض بوت استرپ که در داخل کارت اضافه شده است، کار میکند. توصه میشود که بر اساس استانداردهای تجربه کاربری موبایل، مسیر سایت شما هرگز نباید آنقدر عمیق باشد که نیاز به مسیر داشته باشد. از این المان فقط در جایی که لازم است استفاده کنید.
