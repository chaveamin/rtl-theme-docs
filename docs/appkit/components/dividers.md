# جدا کننده ها

هدف جدا کننده ها این است که بین محتوا و المان های شما کمی فاصله ایجاد کند. استفاده از آنها بسیار آسان است. جدا کننده ها میتوانند از کلاس های کمکی برای رنگ پس زمینه با استفاده از کلاس `bg-VALUE` استفاده کنند، میتوانید رنگ های موجود در قالب را در [بخش رنگ ها](/appkit/color-highlights-backgrounds) پیدا کنید.

تقسیم‌کننده‌ها تکه‌های کوچکی از کد هستند که میتوانید در صفحه **component-dividers.html** پیدا کنید. اگر از تقسیم‌کننده استفاده میکنید و میخواهید تمام عرض باشد، از کلاس تقسیم‌کننده `bg-VLAUE` استفاده کنید. اگر میخواهید جداکننده شما حاشیه چپ و راست یکسانی با محتوای شما داشته باشد، کافیست کلاس `divider-margins` را به عنوان یک کلاس کمکی اضافه کنید.
