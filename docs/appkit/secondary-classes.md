# کلاس های ثانویه(کمکی)

کلاس‌های ثانویه، قطعات CSS قابل استفاده مجددی هستند که برای بهبود و گسترش ویژگی‌های خاص به HTML شما اضافه میشوند. به عنوان مثال، ممکن است بخواهید از یک رنگ دوباره استفاده کنید، بنابراین به جای نوشتن مجدد CSS برای هر بار که آن رنگ را میخواهیم، ​​یک کلاس برای آن ایجاد میکنیم. اینها کلاس‌ های پیشفرض Bootstrap هستند که در [Bootstrap](https://getbootstrap.com/docs/5.3/utilities/spacing/) در دسترس هستند.

اما، در کنار این کلاس‌ ها، میخواستیم انعطاف‌ پذیری بیشتری به شما ارائه دهیم، در حالی که قرارداد نامگذاری معمول Bootstrap را حفظ میکنیم

**نمونه ای از یک تگ با کلاس های کمکی**

```html
<h1 class="font-16 font-800 text-uppercase pt-3 mb-0">I'm a heading</h1>
```

تگ h1 بالا چند کلاس متصل دارد که هر کدام هدف متفاوتی دارند. میتوانید اندازه فونت، وزن فونت، متن را تغییر دهید و حتی فاصله بین خطوط و حاشیه‌ها را تنظیم کنید.
همه کلاس های کمکی را میتونید در مستندات [Bootstrap](https://getbootstrap.com/docs/5.3/utilities/spacing/) مطالعه کنید.
