# منوها

سیستم‌ منو اختصاصی ساخته شده‌ است تا دارای جلوه های زیباتر از سیستم‌های پیشفرض موجود در بوت استرپ باشند. آن‌ها برای استفاده کامل از CSS بسیار خوب بهینه‌سازی شده‌اند و حتی بر روی موبایل های قدیمی نیز بدون مشکل کار خواهند کرد

:::info

منوهای نشان داده شده در اینجا سفارشی ساخته شده اند. مدال هایی که بوت استرپ ارائه میدهد با صفحات قالب کاملا سازگار هستند اما نمیتوانند با منوهای قالب ترکیب شوند. همانطور که در اینجا با استفاده از سیستم آنها نشان داده شده است، میتوانید از [مدال های بوت استرپ](https://getbootstrap.com/docs/5.3/components/modal/) استفاده کنید

:::
