# صفحات ساخته شده با المان

صفحات زیر برای ویرایش فقط نیاز است که آن را باز و المان ها را دورن آن کپی و پست کنید، یا اینکه سبک یا محتوای خود را با آنها سازگار کنید. این صفحات در مستندات پوشش داده نمیشود، اما لینک هایی به المان هایی که برای ساخت آنها استفاده شده است، قرار داده میشود تا محتوای داخل صفحه را بهتر درک کنید
