# راهنما

## نصب نسخه whmcs

### ساختار فایل زیپ

```bash
bredh
├── HTML
└── WHMCS x.x.x
    └── templates
        ├── bredh-noon
        ├── bredh-sefar
        └── orderforms

```

برای نصب قالب پوشه `WHMCS x.x.x` را در محل نصب whmcs خود آپلود کنید.\
سپس در تنظمات عمومی و قالب و فرم سفارش را تغییر دهید.

## نصب نسخه html

برای نصب این نسخه کافیه پوشه `HTML` را در هاست خود آپلود کنید.

:::rtnote نکات

1. برای شخص سازی هر دو نسخه نیازمند دانش کدنویسی هستید.
2. جهت هرگونه شخصی سازی یا راهنما از طریق [تیکت](https://www.rtl-theme.com/dashboard/#/ticket-send) در راست چین در ارتباط باشید.

:::
