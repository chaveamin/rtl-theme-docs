# صفحات ساخته شده با المان

صفحات زیر برای ویرایش فقط نیاز است که آن را باز و المان ها را دورن آن کپی و پست کنید، یا اینکه سبک یا محتوای خود را با آنها سازگار کنید. این صفحات در مستندات پوشش داده نمیشود، اما لینک هایی به المان هایی که برای ساخت آنها استفاده شده است، قرار داده میشود تا محتوای داخل صفحه را بهتر درک کنید

:::rtnote نکته

برا شناسایی بهتر صفحات، نام آنها به انگلیسی مطابق آن در پکیچ قالب نوشته شده است

:::

- **page-about:** ساخته شده با استفاده از [کارت‌های ارتفاع ثابت](/appkit/components/cards#height-control) و [کلاس‌های کمکی](/appkit/secondary-classes) برای تایپوگرافی
- **page-careers:** ساخته شده با استفاده از تصاویر با [کلاس‌های کمکی](/appkit/secondary-classes) برای سایه، گوشه‌های گرد و [دکمه‌ها](/appkit/components/icons-btns)
- **page-events-cards:** ساخته شده با استفاده از [کارت‌های ارتفاع ثابت](/appkit/components/cards#height-control)
- **page-events-details:** ساخته شده با استفاده از [کارت‌های ارتفاع ثابت](/appkit/components/cards#height-control)
- **FAQ's:** ساخته شده با استفاده از [المان جستجو](/appkit/components/search) و [المان collapse](/appkit/components/collapse)
- **page-instants:** ساخته شده با استفاده از [سایدبارها](/appkit/components/sidebar) برای مقالات، [کارت‌های ارتفاع ثابت](/appkit/components/cards#height-control) درون [ستون‌ها](/appkit/components/columns) و [رنگ ها](/appkit/color-highlights-backgrounds#%DA%86%D9%87-%D8%B1%D9%86%DA%AF-%D9%87%D8%A7%DB%8C%DB%8C-%D8%A8%D9%87-%D8%B7%D9%88%D8%B1-%D9%BE%DB%8C%D8%B4%D9%81%D8%B1%D8%B6-%DA%AF%D9%86%D8%AC%D8%A7%D9%86%D8%AF%D9%87-%D8%B4%D8%AF%D9%87-%D8%A7%D8%B3%D8%AA)
- **page-system-status:** ساخته شده با استفاده از [اعلان ها](/appkit/components/notif-alerts#%D8%A7%D8%AE%D8%B7%D8%A7%D8%B1%D9%87%D8%A7)
- **page-user-edit:** ساخته شده با استفاده از [گروه‌های لیست](/appkit/components/link-lists-groups) و [سویچ ها](/appkit/components/toggles-switches)
- **page-terms:** ساخته شده با استفاده از [کارت‌های Expanding](/appkit/components/cards#expanding-card) و تایپوگرافی
- **page-team:** ساخته شده با استفاده از [ستون‌ها](/appkit/components/columns)، [آیکون ها](/appkit/components/icons-btns#%D8%A2%DB%8C%DA%A9%D9%88%D9%86-%D9%87%D8%A7) و [کلاس‌های کمکی](/appkit/secondary-classes) برای سایه‌، حاشیه‌ و رنگ‌ها.
- **page-timeline:** ساخته شده با استفاده از آیکون های FontAwesome و کپی پیست المان ها
- **page-vcard:** ساخته شده با استفاده از کپی پیست المان v-card.
- **cards:** ساخته شده با استفاده از [کارت‌های ارتفاع ثابت](/appkit/components/cards#height-control) و [کلاس‌های کمکی](/appkit/secondary-classes) برای سایه‌، حاشیه‌ و رنگ‌ها.
- **page-wallet:** ساخته شده با استفاده از [تب‌ها](/appkit/components/tabs) همراه با [هشدارها](/appkit/components/notif-alerts#%D8%A7%D8%AE%D8%B7%D8%A7%D8%B1%D9%87%D8%A7) و [گروه‌های فهرست](/appkit/components/link-lists-groups)
- **page-profile:** ساخته شده با استفاده از [کارت‌های ارتفاع ثابت و Expanding](/appkit/components/cards) به همراه گالری‌های [ستونی](/appkit/components/columns) و بندانگشتی (در زیر توضیح داده شده است)
- **page-system-signin-1, page-system-signup-1, page-system-forgot-1:** ساخته شده با استفاده از اینپوت ها همرا با [کارت‌های Expaning](/appkit/components/cards#expanding-card)
- **صفحات نمونه کار و محصولات:** ساخته شده با استفاده از [کارت‌های ارتفاع ثابت و Expanding](/appkit/components/cards) و [ستون‌هایی](/appkit/components/columns) که با استفاده از [کلاس‌های کمکی](/appkit/secondary-classes) استایل‌دهی شده‌اند
- **مقالات سریع:** ساخته شده با استفاده از [منوهای تمام صفحه](/appkit/menus) و [ستون‌های](/appkit/components/columns) استایل داده شده با استفاده از [کلاس‌های کمکی](/appkit/secondary-classes)

:::rterror

توجه داشته باشید بقیه صفحات را به این دلیل که نمیخواستیم مستندات را بنویسیم، از قلم نینداختیم. این صفحات تقریباً گویای همه چیز هستند. ما چند دستورالعمل در زیر برای صفحاتی که نیاز به دقت بیشتری دارند، اضافه کرده‌ایم.

اگر در مورد هر یک از این صفحات که اضافه نشده است به کمک بیشتری نیاز دارید یا برخی از بخش های آنها را درک نمیکنید، با **[ارسال تیکت در راست چین](https://www.rtl-theme.com/dashboard/#/ticket-send)** با بنده در ارتباط باشید.

:::
