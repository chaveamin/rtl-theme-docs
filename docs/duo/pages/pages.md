# صفحات

اگر مستندات قالب را تا این مرحله خوانده باشید، استفاده از صفحات ساده خواهد بود، زیرا این صفحات با استفاده از [المان های موجود](/appkit/components/main-card-style) ساخته میشوند و با استفاده از [کلاس‌ های کمکی](/appkit/secondary-classes) استایل‌دهی میشوند که به آنها انعطاف‌پذیری، سهولت استفاده و ویرایش را تنها با استفاده از کلاس‌های کمکی و کپی پیست کردن المان ها ارائه میدهد.
